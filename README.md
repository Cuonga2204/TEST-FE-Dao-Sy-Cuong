# TaskBoard — Frontend Test

Ứng dụng quản lý công việc

## Tech stack

- **React 18 + TypeScript 5**
- **Ant Design 5**
- **Redux Toolkit 2**
- **Tailwind CSS 3**
- **Vite 5**
- **React Router 6**
- **dayjs**
- **nanoid**

## Cài đặt và chạy

```bash
npm install
npm run dev      # dev server tại http://localhost:5173
npm run build    # build production
npm run preview  # preview build
npm run type-check
```
